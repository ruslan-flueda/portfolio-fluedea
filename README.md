# FLUEDA portfolio

Ruslan Khairullin's Astro portfolio, based on the FLUEDA Figma desktop design.

## Commands

- `pnpm install` — install dependencies.
- `pnpm dev` — run the local site.
- `pnpm check` — validate Astro and TypeScript.
- `pnpm build` — create the static production build.
- `pnpm deploy` — deploy an already-built `dist/` directory to Cloudflare.

Read `AGENTS.md` and `docs/PROJECT_CONTEXT.md` before changing the implementation.
